# Student Portal

A simple C++ project for practicing Git and GitHub workflows.

## Prerequisites

- Git
- A C++ compiler such as g++
- Visual Studio Code or another C++ editor

## Version Information

The current project version is 1.0.


## Build and Run

Compile the project using:

g++ main.cpp student_info.cpp profile.cpp dashboard.cpp settings.cpp login.cpp -o student_portal

Run the program using:

./student_portal



## Project Features

- Student login and authentication
- Student profile management
- Dashboard information display
- Student settings and preferences
- Profile conflict handling through Git merges
